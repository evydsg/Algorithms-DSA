# 🧠 Algorithms & Data Structures

A structured Python reference for learning and interview preparation, organized by topic with implementations of classic algorithms and data structures.

---

## 📁 Topics Covered

| Topic | Key Concepts | Time Complexity | Space Complexity |
|-------|-------------|----------------|-----------------|
| **Arrays** | Two pointers, sliding window, prefix sums | O(n) – O(n log n) | O(1) – O(n) |
| **Binary Search** | Iterative & recursive search, search on answer | O(log n) | O(1) |
| **Linked Lists** | Traversal, reversal, cycle detection, merge | O(n) | O(1) – O(n) |
| **Trees** | DFS, BFS, BST operations, LCA | O(n) | O(h) – O(n) |
| **Graphs** | DFS, BFS, topological sort, shortest path | O(V + E) | O(V + E) |
| **Heap / Priority Queue** | Min/max heap, k-th element problems | O(log n) per op | O(n) |
| **Sorting** | Merge sort, quicksort, counting sort | O(n log n) avg | O(1) – O(n) |
| **Dynamic Programming** | Memoization, tabulation, 1D/2D DP | O(n) – O(n²) | O(n) – O(n²) |
| **Backtracking** | Permutations, subsets, constraint solving | O(n!) – O(2ⁿ) | O(n) |
| **Recursion** | Base cases, call stack, divide & conquer | Varies | O(n) (call stack) |

> **h** = tree height, **V** = vertices, **E** = edges

## 🚀 Getting Started

**Prerequisites:** Python 3.x

**Clone the repo:**
```bash
git clone https://github.com/evydsg/Algorithms-DSA.git
cd Algorithms-DSA
```

**Run any file:**
```bash
python "Binary Search/binary_search.py"
```
